# Decision Tree Learning Playground 🌳

An interactive web application that helps users understand how **Decision Trees** work in Machine Learning through visualizations, simulations, and quizzes.

The project focuses on making tree-based models **easy to understand using interactive learning instead of only theory.**

---
Live at:  
https://decision-tree-lab.vercel.app/

---
## Features

### Intro
Brief explanation of decision trees with a simple animated tree simulation.

### Metrics
Explore how trees choose splits using:
- Gini Impurity
- Entropy
- Information Gain

### AI Challenge
Interactive challenge where users try to predict outcomes before the model.

### Model Complexity
Visual explanation of:
- Underfitting
- Balanced Model
- Overfitting

### Advanced Models
Introduction to ensemble techniques:
- Random Forest
- Gradient Boosting
- Pruned Trees

### Quiz
Test your understanding of decision tree concepts.
